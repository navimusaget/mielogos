Governance

Governance you can inspect.

The current rules of Mielogos should be easy to find, and institutional change should remain visible without making every visitor navigate an archive.

Current instruments first. Decisions and amendments next. Superseded texts preserved, but never confused with what governs now.

Public rule

One current state.
Visible history.

Mielogos maintains a clear distinction between current governing instruments and the records that explain how those instruments came to exist.

Website summaries are navigation aids. The authoritative files are the adopted documents themselves. Their versions and checksums are published here so the public record can be inspected without requiring technical expertise.

Integrity

A public record that can be checked.

Every public governance file listed on this page has a SHA-256 checksum recorded in a machine-readable register. This makes accidental or unexplained file changes detectable without turning the website into a technical repository.

Open the machine-readable governance register.

Drafts, working notes, and testing materials do not acquire normative authority merely because they exist. Only formally active instruments and recorded institutional decisions govern the Association.

Why this matters

Trust should not require guessing how the institution works.

Mielogos is intentionally small at launch. Its governance can therefore remain understandable as well as inspectable.
